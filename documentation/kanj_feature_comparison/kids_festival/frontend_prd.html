9. Stripe webhook

File: src/app/api/webhooks/stripe/route.ts

On payment_intent.succeeded, when metadata registrationType === 'kids_festival':

  1. Read eventId, kidsRegistrationIds (comma-separated or JSON), tenantId
  2. PATCH registrations to CONFIRMED via direct backend or proxy (service JWT)
  3. Do not alter standard ticket checkout metadata paths
metadata: {
  registrationType: 'kids_festival',
  eventId: '123',
  kidsRegistrationIds: '1,2,3',
  tenantId: 'tenant_demo_002'
}
