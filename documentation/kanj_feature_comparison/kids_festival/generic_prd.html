Executive summary

Problem and solution

Parents need to register children for multiple competitions under one festival event (KGT-style), pay optional per-event fees, and view published results. Today the platform supports adult ticket checkout only.

Solution: Optional is_kids_festival on event_details plus parallel kids_* tables, REST APIs, Next.js routes under /events/[id]/kids-festival/, and admin tools — without overloading event_ticket_type.
