1. Overview

1.1 Current Situation

The existing POST /api/cron/subscription-renewal endpoint receives a stripeSubscriptionId parameter in the request body, but it's not being passed to the batch job service. This prevents testing specific subscriptions.

Current Backend Log:

WARN: stripeSubscriptionId parameter is provided but not yet supported by batch job service.
The batch job will process all subscriptions for the tenant.
stripeSubscriptionId: sub_1SeifsK5BrggeAHMBvg2XE93

1.2 What We're Adding

  • Pass stripeSubscriptionId to batch job - When provided in the request, pass it as a job parameter
  • No API changes - Same endpoint, same request/response format
  • Backward compatible - If stripeSubscriptionId is not provided, behavior is unchanged

1.3 What Remains Unchanged

✅ The scheduled batch job (runs every 6 hours) is completely unaffected:

  • Still runs on schedule (every 6 hours)
  • Still processes subscriptions expiring within 7 days
  • Still uses the same query logic
  • No changes to scheduled job configuration

2.3 Updated Code (After Fix)

Java - Updated Implementation
public BatchJobResponse submitSubscriptionRenewalJob(BatchJobRequest request) {
    // Build job parameters
    JobParametersBuilder jobParametersBuilder = new JobParametersBuilder();
    jobParametersBuilder.addString("tenantId", request.getTenantId());
    jobParametersBuilder.addLong("timestamp", System.currentTimeMillis());

    // ✅ FIX: Pass stripeSubscriptionId if provided (for testing specific subscriptions)
    if (request.getStripeSubscriptionId() != null &&
        !request.getStripeSubscriptionId().isEmpty()) {
        jobParametersBuilder.addString("stripeSubscriptionId",
            request.getStripeSubscriptionId());
        log.info("Passing stripeSubscriptionId to batch job for testing: {}",
            request.getStripeSubscriptionId());
    }

    // Submit job to batch service
    JobExecution jobExecution = jobLauncher.run(
        subscriptionRenewalJob,
        jobParametersBuilder.toJobParameters()
    );

    return buildResponse(jobExecution, request);
}

2.4 Key Changes

  1. Remove the warning log - No longer needed since we're supporting it
  2. Add stripeSubscriptionId to job parameters - Pass it to the batch job when provided
  3. Add info log - Log when passing subscription ID for testing
