Base path

All admin routes require service JWT + X-Tenant-ID. JSON field names match src/types/profileSite.ts (camelCase).

Bulk import body

[
  { "email": "reader@example.com", "firstName": "Jane", "source": "CSV_IMPORT" },
  { "email": "fan@example.com", "optInStatus": "OPTED_IN" }
]

Response: { imported, updated, skipped, errors[] } (see ProfileAudienceBulkImportResultDTO).

Send flow

  1. Admin calls send-to-profile-audience with template id
  2. Service resolves opted-in emails for tenant (or delegates to batch-jobs PROFILE_AUDIENCE reader)
  3. Batch job sends via AWS SES; log in promotion_email_sent_log
