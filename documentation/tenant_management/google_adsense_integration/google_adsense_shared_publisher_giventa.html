Google AdSense — Shared Publisher ID (giventa.com)

Model: A — Shared Publisher ID  |  AdSense account domain: giventa.com  |  Companion: Owner setup guide  |  Updated: June 2026

This page records the production shared Publisher ID registered with giventa.com in Google AdSense. Use it for Model A (application owner receives all ad revenue) on satellite domains such as www.mosc-temp.com.

If a satellite tenant does not have their own per-tenant Publisher ID (Model B), enter the values below in Tenant Settings → Integrations → Google AdSense and deploy the matching ads.txt and meta tag on that domain.

1. Admin app — Tenant Settings (Integrations)

For each satellite tenant that uses the shared owner ID (not their own Model B account):

  1. Open Tenant Management → Settings → Edit → Integrations tab.
  2. Enable Google AdSense.
  3. Paste Publisher ID: ca-pub-1016198353275904.
  4. Enter ad unit slot IDs per region (sidebar, between_sections, footer_strip) from the AdSense dashboard for that satellite domain.
  5. Save.

Per-tenant vs shared: Slot IDs are usually unique per domain even when the Publisher ID is the same. Create separate ad units in AdSense for each satellite site; only the ca-pub-... stays identical across tenants on Model A.

2. AdSense script snippet

Google provides this snippet for site verification / auto ads. The app loads the same script dynamically when ads are enabled (src/components/ads/GoogleAdSenseSlot.tsx). Keep this copy for manual HTML pages or AdSense dashboard reference.

<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-1016198353275904"
     crossorigin="anonymous"></script>

3. ads.txt

Deployed in this repo at public/ads.txt. Must return HTTP 200 at https://YOUR-SATELLITE-DOMAIN/ads.txt.

google.com, pub-1016198353275904, DIRECT, f08c47fec0942fa0

If a tenant later uses their own Publisher ID (Model B), that domain’s ads.txt must list their pub-... line instead — not this shared owner line.

4. Meta tag (account association)

Added in src/app/layout.tsx for satellite deploys. Override via env NEXT_PUBLIC_GOOGLE_ADSENSE_SHARED_PUBLISHER_ID if needed.

<meta name="google-adsense-account" content="ca-pub-1016198353275904">
