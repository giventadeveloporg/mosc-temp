What to leave behind vs what to invent

⚠️ Explicit anti-patterns (current look)

Do not reproduce the present /mosc-redesign visual language:

  • Warm cream / parchment page backgrounds (#F5F1E8-class), burgundy strip accents, “sacred brochure” card grids
  • Dark brown hero bar (#1a1410) with a dense 5-column burgundy quick-access strip
  • Purple frosted-glass / neon analytics dashboard aesthetic
  • Default stacks (Inter, Roboto, Arial, system-ui) as the primary voice
  • Generic purple-on-white or purple→indigo AI default themes
  • Newspaper broadsheet density (hairline rules, zero radius, cramped columns)
  • Hero clutter: floating badges, promo chips, stats strips, or multiple competing headlines in the first viewport
✨ Target direction — “Liturgical Sapphire & Kerala Copper”
  • Atmosphere: Deep sapphire / ink night for immersive planes; soft stone-ivory for reading planes; warm copper + antique gold as sacred accent metals (not terracotta cream).
  • Typography: Expressive display serif for brand/headlines + humanist sans for UI; support Malayalam (e.g. Anek Malayalam or equivalent). Brand name must be a hero-level signal.
  • Composition: Editorial magazine rhythm — asymmetric splits, full-bleed media, generous whitespace, one job per section.
  • Layout rearrange OK: Reorder sections, change column ratios, convert the quick-access bar into a slim rail or icon ribbon — but keep every content purpose.
  • Motion: 2–3 intentional motions (hero crossfade, gentle section reveal, hover lift) — restrained, reverent, reduced-motion safe.

Master prompt — Total revamp · Shell + Homepage + System 
You are designing in Claude Design Desktop using model Fable 5.

PROJECT
Redesign the Malankara Orthodox Syrian Church (MOSC) public site section currently living at /mosc-redesign (conditional layout: its own header/footer/shell, separate from the main app chrome). Produce a COMPLETELY NEW visual design language for:
1) Shared shell (header, navigation, footer, page canvas)
2) Homepage composition (desktop 1440 and mobile 390)
3) A reusable system that extends cleanly to subpages (hub grids, article lists, calendars, downloads, forms, detail profiles)

Reference live URL for CONTENT structure only (NOT visual style): http://localhost:3000/mosc-redesign
If screenshots of the current site are attached, treat them as “CURRENT — DO NOT IMITATE.”

NON-NEGOTIABLES
- Retain ALL existing content purposes and information architecture. You may rearrange section order, column ratios, and component shapes — never delete a content role.
- Domain identity stays Orthodox Christian / Malankara Syrian Church: apostolic heritage (St. Thomas, AD 52), Catholicate, Holy Synod, dioceses worldwide, liturgy, saints, news, publications, seminaries, spiritual organizations.
- Bilingual readiness: English + Malayalam UI patterns (language toggle for liturgy readings).
- Accessibility: WCAG AA contrast, visible focus, keyboard nav, alt text for sacred imagery, respect prefers-reduced-motion.
- First viewport must read as ONE composition (not a dashboard). Brand “Malankara Orthodox Syrian Church” is a hero-level signal. Hero media is full-bleed edge-to-edge. No floating badges, promo chips, or stats strips on the hero. First viewport budget: brand + one headline + one short supporting line + one CTA group + one dominant image plane.
- Cards are allowed only when they are interaction containers (hub tiles, news items, download rows). Prefer editorial layouts over card spam.
- Portraits of clergy/saints: show full faces; prefer contained framing over aggressive crop.

EXPLICITLY REJECT (current / AI-default looks)
- Warm cream parchment backgrounds + burgundy “church brochure” strips
- Terracotta / earth-tone sacred template look
- Purple frosted-glass neon analytics UI
- Purple-on-white or purple→indigo gradient themes
- Broadsheet newspaper density (hairline rules, zero radius, cramped columns)
- Inter / Roboto / Arial / system as primary brand fonts
- Cluttered multi-block first viewport

NEW VISUAL DIRECTION — “Liturgical Sapphire & Kerala Copper”
Invent a premium contemporary sacred identity that feels distinct from the current site:

Palette (define exact tokens):
- Night sapphire / deep ink for immersive planes and hero atmosphere
- Soft stone ivory / cool parchment for long-form reading surfaces (NOT warm cream beige)
- Copper + antique gold for sacred metal accents, rules, and focus rings
- Deep teal or indigo for secondary interactive accents
- Clear semantic status colors only where needed (news tags, calendar states)

Typography:
- Distinctive display serif for brand wordmark and section titles
- Humanist sans for navigation, body, and data
- Malayalam-capable companion for bilingual blocks
- Strong hierarchy; avoid tiny gray body text

Texture & craft:
- Subtle liturgical atmosphere (soft light falloff, quiet grain, or architectural shadow) — never loud particle neon
- Occasional copper hairlines or cross-inspired geometric motifs used sparingly as section punctuation
- Real photography: Aramana, worship, portraits, Kerala/India heritage — treat images as the visual anchor

HOMEPAGE CONTENT MAP (retain every block; redesign presentation)
A. Full-bleed hero slideshow (worship scene + Aramana banner). Brand-forward. One primary CTA (e.g. Explore The Church / Catholicate News). Desktop + mobile.
B. Quick access: Catholicate News, Downloads, E-Mail, Gallery, Contact Info — reinvent as a slim editorial ribbon/rail (not a heavy burgundy 5-column strip).
C. About Us: heritage narrative + three heritage images (Christ/St. Thomas, Bishops, Cross) + Saints carousel entry.
D. Current Catholicos featured profile (portrait, role, heading, excerpt, link to profile).
E. Liturgy of the day: date, EN/ML toggle, reading list panel — calm, readable, sacred.
F. Dioceses worldwide: interactive/world map region chips (South West America, North East America, UK, Africa, India) with clear regional entry.

SHELL / NAV CONTENT (retain)
Primary: Home, The Catholicate, Administration, The Church, Holy Synod, Ecumenical, Dioceses, News, Saints
Utility: Calendar submenu (Liturgical + MOSC calendars), Search Directory, sign-in/avatar
Footer quick links: Catholicate News, Downloads, E-Mail, Gallery, Contact Info
Secondary destinations remain reachable: Spiritual Organisations, Publications, Institutions, Training, Theological Seminaries, Lectionary, Downloads, Gallery

LAYOUT PERMISSIONS
- You MAY restructure the homepage section order for better narrative flow (e.g. Catholicos closer to hero, liturgy as quiet mid-page chapel, map as closing world-church statement).
- You MAY redesign hub subpages as editorial grids with consistent media framing and typography — not the current parchment card collage.
- Keep sticky header workable on mobile.

MOTION
Ship 2–3 intentional motions only: hero image crossfade or slow ken-burns (subtle), section fade/slide-in once, hover lift on interactive tiles. No noise.

OUTPUT REQUESTED FROM FABLE 5
1) Desktop homepage artboard (~1440 wide) with annotated sections
2) Mobile homepage artboard (~390 wide)
3) Shared header + footer states (default, scrolled/sticky, mobile open menu)
4) Design tokens sheet: colors, type scale, spacing, radii, elevation, focus, motion
5) 2–3 subpage templates: (a) portrait hub grid, (b) news/list, (c) detail/profile — same system as homepage
6) Short rationale (5–8 bullets) explaining how this look differs from cream/burgundy and why it still feels authentically MOSC / Orthodox

Tone: reverent, confident, modern, culturally rooted in Kerala–Malankara Orthodoxy — not corporate SaaS, not gothic cosplay, not festival poster clutter.
